# Ejemplos del tutorial por idioma de voz

El orden enseñado es evento → equipo → jugador 1 → jugador 2. Se usan conectores y preposiciones naturales dentro de ese orden. Las identidades ficticias conservan #7 y #9 al adaptar sus nombres; los nombres introducidos por el usuario no se traducen. C siempre identifica al infractor rival #12 por número y a la beneficiaria propia #9 por nombre. D omite deliberadamente #8 para completarlo en el editor.

Estas frases y las cuatro piezas de la introducción pasan por el intérprete y evaluador reales. El evento se reconoce literalmente y el equipo de forma explícita. No se modifica ASR/parser para acomodarlas. La comprobación acústica disponible usa solo audio sintético español.
